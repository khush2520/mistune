# ADR 008 · Start each review with a clean context

**Status**

Proposed in the initial design.

## Context

A reviewer needs to challenge the proposed change on evidence from the PR.

## Decision

Give it a clean read-only job and prompt. Validate file and line evidence, then publish the verdict with a separate token.

## Alternative considered

A review turn in the implementer's conversation would reveal rationale and make agreement easier.

## Consequences

GitHub shows a review comment on the tested SHA. A real approval for merge remains a human action.
