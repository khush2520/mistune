# ADR 005 · Give agents fixed operations

**Status**

Proposed in the initial design.

## Context

Issue text and generated tests can contain instructions or executable code.

## Decision

Let the model propose text or file contents. Apply allowed paths in the runner. Use an offline container for generated code and GitHub REST only from trusted jobs.

## Alternative considered

An unrestricted shell or GitHub MCP would give an injected instruction more scope.

## Consequences

Agents cannot install dependencies or edit CI. Tasks needing that scope stop for a maintainer.
