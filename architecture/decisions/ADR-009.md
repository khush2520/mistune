# ADR 009 · Bound execution and constrain untrusted inputs

**Status**

Proposed in the initial design.

## Context

Public issue content and repository files can try to redirect the model or candidate execution.

## Decision

Treat input as data. Allow only bounded source and new test edits. Execute inside a resource-limited container without mounted tokens or network. Limit calls, output, and job duration.

## Alternative considered

Prompt instructions and unrestricted execution would give generated content access to credentials and publish controls.

## Consequences

The sandbox and validator cost time. Model or infrastructure failures leave a failed-stage artifact when the runner can still upload it.
