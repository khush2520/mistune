# ADR 011 · Update the pinned model before the first run

**Status**

Implemented. Replaces ADR 006. The live API has yet to be exercised in this repository.

## Context

The provider lists the GPT-4.1 mini snapshot as deprecated. The choice of one snapshot for all roles still makes agent comparisons easier to read.

## Decision

Use `gpt-5.4-mini-2026-03-17` in each role, with fresh Chat Completions requests and low reasoning effort. Allow an explicitly configured snapshot for access or experiment purposes. Record usage as reported by the API.

## Consequences

The replacement costs more per generated token. The same review and development model can still miss the same edge case. No run data supports a quality comparison between the snapshots.
