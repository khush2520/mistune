# ADR 004 · Keep run state in artifacts

**Status**

Proposed in the initial design.

## Context

A run can stop after any stage and reruns must preserve provenance.

## Decision

Name artifacts by run attempt and round. Use a branch scoped to the run attempt and one PR for both rounds. Preserve immutable issue and SHA inputs across rounds.

## Alternative considered

Committing specs and logs on the product branch would pollute the diff and expose them to the reviewer.

## Consequences

Full reruns start a new attempt. Old PRs remain visible for maintainers to resolve.
