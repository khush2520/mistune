# ADR 003 · Pass checked artifacts to each stage

**Status**

Proposed in the initial design.

## Context

A1 tracks evidence and assumptions. A2 supplies the existing code structure.

## Decision

Pass the issue snapshot and validated spec to design, then file/function targets and the spec to implementation. Send the reviewer the issue, PR diff and final tree.

## Alternative considered

Sending full conversations would give the reviewer the author's framing and make the inputs harder to reproduce.

## Consequences

A gate can be reproduced from its artifact and commit. Some rationale must be restated as a concrete finding.
