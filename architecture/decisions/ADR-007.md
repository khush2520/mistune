# ADR 007 · Require executed tests for acceptance

**Status**

Proposed in the initial design.

## Context

A test can exist and still fail, skip, or never collect.

## Decision

Check Given/When/Then data, declared symbols, a wheel build, and a passing full suite. Require a passing pytest case for every acceptance criterion.

## Alternative considered

Checking for a test name alone would ignore collection and execution failures.

## Consequences

The runner owns pass/fail. The reviewer still needs to judge test meaning.
