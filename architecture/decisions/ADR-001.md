# ADR 001 · Give the reviewer a dedicated role

**Status**

Proposed in the initial design.

## Context

Four roles have different inputs and checks. Release also needs GitHub access.

## Decision

Use a requirements agent, a designer, one implementer/tester role with separate calls, and a reviewer. Use code for release.

## Alternative considered

One agent for all six stages would share assumptions across the whole run. Six agents would add a hand-off between code and tests while release already has a deterministic API contract.

## Consequences

Each model call starts fresh. Implementation and testing still share the plan and the candidate through files.
