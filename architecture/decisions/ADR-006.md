# ADR 006 · Use one pinned model with fresh calls

**Status**

Proposed in the initial design.

## Context

A2 used Codex CLI. A3 needs comparable output and separate model sessions.

## Decision

Start with the gpt-4.1-mini-2025-04-14 API snapshot for every role. Keep prompts separate and record token usage per request.

## Alternative considered

A different reviewer model could diversify failures but would add a second variable to the first experiments.

## Consequences

The model is cheaper to use across several roles. Shared failure modes remain possible.
