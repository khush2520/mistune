# ADR 010 · Authorize the sender and serialize per issue

**Status**

Proposed in the initial design.

## Context

A public user can comment. A label and a command may arrive close together.

## Decision

Accept only autose labels or the exact /autose issue comment from someone with write access or higher, on the configured fork. Use issue-level Actions concurrency.

## Alternative considered

Author association and prefix matching could start runs for callers without repository write access.

## Consequences

One run executes per issue. GitHub can replace a pending run when another arrives.
