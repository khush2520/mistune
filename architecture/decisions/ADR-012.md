# ADR 012 · Run the model on free public runners

**Status**

Accepted for the zero-cost execution path. Supersedes ADR 011.

## Context

The previously selected API model has no free tier. The public assignment fork can use standard GitHub runners at no charge. Model inference now needs to run without a paid API account.

## Decision

Run the pinned Q4_K_M quantization of Qwen2.5-Coder-7B-Instruct using llama.cpp on the job's Linux CPU. Bind inference to loopback and use fixed call and token caps. Each reviewer gets its own job and local model process. Use output schemas and exact text replacements to keep generation short.

## Consequences

The workflow cannot incur model API charges. It spends additional runner time loading the weights. A smaller model may stop at more gates, and the runner records those failures. Until the setup PR is reviewed, manual dispatch lets the protected fork exercise the revised workflow without changing main.
